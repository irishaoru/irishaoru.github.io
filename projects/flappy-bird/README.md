# Customizable Flappy Bird

A Python game created as a Carnegie Mellon 15-112 term project using the `cmu_graphics` library.

## Features

- Adjustable difficulty, gravity, and flying speed
- Sliding and variable pipe gaps
- Multiple collectible food modes
- Enemy mode
- Computer-controlled opponent with adjustable difficulty
- Score, lives, and high-score tracking

## Run locally

Install the CMU Graphics package, then run:

```bash
python3 flappy_bird.py
```

The game is a desktop Python application and cannot run directly on GitHub Pages.
