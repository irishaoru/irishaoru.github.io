# CMU Crossy Road

## What the game is and how it differs from stock Crossy Road 
My game is a variation of Crossy Road except it is a CMU version. So instead of a duck, the player is a CMU student and they are walking across campus, tring to avoid hitting buses, scooters, bikes and other students on their way. 

## How to Play
Basically the same as Crossy Road. 
- Use the arrow keys to move forward, backward, left, and right.
- Avoid hazards such as buses, scooters, bikes, and students.
- Scoring is based on how many steps the student takes 
There is a version where there is a countdown timer and players can choose different levels (easy, medium, hard)
- Their goal is to walk from Maggie Mo to Tepper before the countdown timer runs out.
- The game ends if you collide with a hazard or run out of time.
- Scoring is based on how fast the player is. 

## AI Tools Used
I used Kiro with the auto mode to help build and modify the game.

My overall strategy was to first create the basic Crossy Road gameplay, then gradually customize the visuals, hazards, map, and mechanics to fit the CMU campus theme.
